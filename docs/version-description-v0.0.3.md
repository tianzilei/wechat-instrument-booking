# 仪器预约小程序 v0.0.3 版本描述

版本：v0.0.3

更新日期：2026-06-19

适用场景：小程序上传更新说明、内部发布记录、阶段性版本概述

---

## 1. 简短版

`v0.0.3` 聚焦预约主链路、管理效率和交互收敛。版本完成了维护时间创建优化、预约与候补反馈补强、周历展示分级、管理待办入口统一，以及“我的 / 管理”页面 dashboard 与底部导航的一致化整理，同时补齐了一轮逻辑、安全、性能与可靠性修复，使当前版本在业务流程、权限边界和前后端连接稳定性上更完整。

## 2. 可直接用于上传更新说明

优化预约、候补与维护流程，统一管理待办入口，新增“我的课题”与导出增强，完善周历展示权限和底部导航样式，并修复一批逻辑、安全与稳定性问题。

## 3. 详细版

本版本不扩展核心业务边界，重点围绕“更顺手地预约和维护”“更直达地处理管理任务”“更稳定地完成前后端交互”三条主线进行收敛。

本次更新主要包括：

- 优化维护时间创建与管理员周历操作链路，空闲格可直接进入维护创建，已预约与维护格按状态分流。
- 统一管理首页入口，将注册待审、课题待审、取消待审和隐私请求收敛到更直达的 dashboard 待办结构。
- 收敛时段治理模型，下线受限时段主入口，仅保留维护规则。
- 调整周历展示权限，形成“游客 / 同课题成员 / 管理员”三级可见规则。
- 新增“我的课题”入口，支持查看课题成员与课题内未来及近 7 天已开启预约记录。
- 保留并补强候补链路，占用格可直接加入候补，候补确认与转正反馈更清晰。
- 运营数据导出扩展为管理员可导出课题组与预约人信息，并同步更新隐私与导出说明。
- 统一底部导航和 `我的 / 管理` dashboard 视觉规范，明确选中态和 `2 x 2` 指标卡尺寸。
- 修复多项逻辑与边界问题，包括注册/课题确认状态流转、项目简称缓存同步、工作时间迁移触发、候补队列互斥与维护冲突处理。
- 加固后台任务与云函数安全边界，补足内部任务权限校验，并修复统计幂等、任务抢占和迁移并发等可靠性问题。
- 优化前后端连接体验，补充会话初始化等待与连接失败反馈，降低首屏状态错乱和静默失败问题。
