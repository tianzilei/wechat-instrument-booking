# 仪器预约小程序 Style Guide

版本：v1.0

更新日期：2026-06-19
设计方向：Instrument Console（实验室仪器控制台）

业务与交互状态以 [`execution-baseline-v2.md`](./execution-baseline-v2.md) 为准。本规范只定义视觉结构、组件表现、响应式行为和验收标准，不得反向修改业务规则。

参考方法：

- Frontend Design：<https://github.com/anthropics/skills/tree/main/skills/frontend-design>
- Theme Factory：<https://github.com/anthropics/skills/tree/main/skills/theme-factory>

## 1. 设计目标

界面服务于单台实验室仪器的高频预约与审核工作。用户应当快速完成三件事：看清时段状态、准确选择时间、确认当前操作结果。

整体风格必须安静、清晰、可信，接近排程控制台，而不是营销页面或内容社区。

## 2. 核心原则

1. 周历是第一视觉重点，其他页面保持克制。
2. 原生导航栏承担页面标题，内容区不重复放置大标题。
3. 使用文字、间距、细分隔线和低饱和状态色建立层级。
4. 普通列表采用白色全宽分组，不把每一行做成悬浮卡片。
5. 图片、插画和装饰性图标默认禁止使用。
6. 不使用图标宫格；导航和管理入口优先使用文字。
7. 不使用渐变、光斑、装饰背景或大面积主题色。
8. 不增加页面转场、弹窗动效或持续动画。
9. 状态不能只依靠颜色，必须同时显示文字或标记。
10. 所有按钮、弹窗和文字必须适配窄屏与系统字体放大。

## 3. 主题令牌

主题令牌统一维护在 `miniprogram/styles/tokens.wxss`，页面和组件不得重复硬编码主题颜色。

| --- | --- | --- |
| 页面背景 | `--color-bg` | `#F4F7F7` |
| 内容背景 | `--color-surface` | `#FFFFFF` |
| 次级背景 | `--color-surface-muted` | `#EEF3F3` |
| 控件边框 | `--color-border` | `#D5DEDD` |
| 内容分隔线 | `--color-divider` | `#E6ECEB` |
| 主文字 | `--color-text` | `#172321` |
| 辅助文字 | `--color-text-secondary` | `#566762` |
| 弱化文字 | `--color-text-muted` | `#74827E` |
| 主操作 | `--color-primary` | `#0F766E` |
| 主操作按下 | `--color-primary-pressed` | `#0B5F59` |
| 主操作浅底 | `--color-primary-soft` | `#DFF2EF` |
| 审核信息 | `--color-accent` | `#1D5F8A` |
| 审核信息浅底 | `--color-accent-soft` | `#E1EFF8` |
| 成功 | `--color-success` | `#2F6F4E` |
| 成功浅底 | `--color-success-soft` | `#E4F1E9` |
| 警示/受限 | `--color-warning` | `#956515` |
| 警示浅底 | `--color-warning-soft` | `#FBF0D2` |
| 危险/错误 | `--color-danger` | `#A43B32` |

| 维护浅底 | `--color-maintenance-soft` | `#F4E7E5` |

主题调整遵循 Theme Factory 的“语义令牌优先”原则：只修改 `tokens.wxss` 中的令牌值，不在页面内批量替换颜色。换色后必须同时检查主色、信息、警示、危险、维护、过去六组状态在白底和浅底上的对比度；不得通过自动生成大量同色阶，让界面退化为单一色系。

## 4. 字体层级

使用微信系统默认中文字体，字距保持 `0`。

| 内容 | 字号 | 字重 |
| --- | --- | --- |
| 页面内主要标题 | `30rpx` | 700 |
| 区块标题 | `24rpx` | 600 |
| 正文和按钮 | `28rpx` | 400-600 |
| 辅助说明 | `24rpx` | 400 |
| 周历及状态小字 | `22rpx` | 400-600 |
| 核心统计数字 | `36rpx` | 700 |

普通页面允许文字自然换行。周历格保持固定尺寸，最多显示两行并省略溢出内容。

## 5. 页面布局

- 普通页面最大宽度为 `960rpx`，居中显示。
- 周历使用全部可用宽度。
- 页面左右边距为 `24rpx`。
- 区块间距为 `24rpx`。
- 白色内容分组使用 `.surface-section`。
- 点击列表行最小高度为 `88rpx`，个人面板入口建议为 `96rpx`。
- 页面背景使用浅灰色，内容分组使用白色。
- 禁止卡片嵌套卡片。

推荐间距只使用以下档位：`4/8/12/16/24/32/48rpx`。常规圆角只使用 `6/8/12rpx`；列表分组和工具面板不超过 `8rpx`，弹窗最多 `12rpx`。

## 6. 导航

### 原生导航栏

- 白色背景、黑色标题。
- 页面内容不重复显示同名大标题。
- 必要说明使用 `.page-intro`，不使用宣传式副标题。

### 底部导航

- 只使用文字，不使用图标。
- 高度约 `100rpx`，并适配底部安全区。
- 文字为 `28rpx`、中等字重。
- 未选中项使用辅助文字色。
- `周历` 选中项使用 `--color-primary`。
- `我的` 选中项使用 `--color-accent`。
- `管理` 选中项使用 `--color-maintenance`。
- 顶部只使用一条细分隔线，不使用阴影或胶囊背景。
- 自定义 tabBar 的选中颜色必须直接作用到文字节点本身，不能只依赖父容器颜色继承。
- 若微信自定义 tabBar 组件对 WXSS 变量继承或主题切换支持不稳定，可在组件脚本或模板中直接绑定颜色值；但颜色语义仍必须与 `--color-primary / --color-accent / --color-maintenance / --color-text-secondary` 一一对应。
- 底部导航是唯一允许为稳定选中态而在组件脚本或模板中写入少量颜色字面量的区域；禁止把这种例外扩散到普通页面和业务组件。

## 7. 按钮与表单

### 按钮

- 标准按钮高度为 `80rpx`。
- 紧凑按钮高度为 `64rpx`。
- 主操作：深青绿实心。
- 次操作：白底青绿描边。
- 危险操作：白底砖红描边或砖红文字。
- 禁用操作：灰底灰字，保持原尺寸。
- 并排按钮必须等高，文字水平和垂直居中。
- 同一操作组最多一个主按钮；取消、返回和清空不能使用主色实心。
- 加载中保持按钮原宽高，文字替换为“提交中”或“处理中”，不插入会改变布局的图标。
- 页面内按钮距离屏幕边缘至少 `24rpx`；固定操作区必须计入安全区。

### 输入框

- 白色背景、`1rpx` 冷灰边框、`8rpx` 圆角。
- 单行控件最小高度为 `80rpx`。
- 多行输入框最小高度为 `160rpx`。
- 标签放在输入框上方，占位符不能替代字段名。
- 错误信息显示在字段下方，不只改变边框颜色。
- 必填标记放在字段标签旁；隐私说明放在相关字段组之前，不在每个输入框重复。
- 字数统计只用于有明确长度限制的多行输入，例如备注和拒绝原因。

## 8. 列表与统计

- 普通列表行使用 `.list-card`，实际呈现为线性列表行。
- 行与行之间使用 `#E6ECEB` 分隔线。
- 不为每一行添加圆角、阴影或独立灰色外边距。
- 状态标签位于摘要行右侧。
- 列表摘要只展示快速判断所需信息，详情进入后续页面查看。
- 统计数字可使用小型 `2 x 2` 网格，但不得嵌套在其他卡片中。
- 趋势和月度统计优先使用表格或文字行，不使用装饰性图表。

### Dashboard 统一语言

- `我的` 与 `管理` 页共享相同的 dashboard 结构：顶部摘要条、`2 x 2` 指标卡、线性入口列表。
- 摘要条使用 `.surface-section` 承载，左侧放核心信息，右侧放状态标签。
- 指标卡允许使用顶部 `6rpx` 强调线，但不得增加阴影、渐变或图标。
- `我的` 页使用 `--color-accent` 作为 dashboard 强调色。
- `管理` 页使用 `--color-maintenance` 作为 dashboard 强调色。
- 课题页等二级页面可复用 `我的` 页的蓝色 dashboard 语义。

## 9. 周历

- 日期表头和左侧时间列固定。
- 手机端保证约三个日期列可读，宽屏可显示完整七天。
- 小时格高度固定为约 `96rpx`。
- 可预约：白底冷灰边框。
- 已预约：浅青绿底和主题色边缘。
- 待审核：浅蓝底和蓝色文字。
- 维护：浅砖红底和砖红边缘。
- 受限：浅琥珀底和琥珀文字。
- 已选：主题色描边、浅底和“已选”文字。
- 维护状态不使用斜纹或渐变。
- 图例为单行横向滚动，不自动换行。
- 多选操作栏固定在网格顶部，按钮不得超出屏幕。

## 10. 弹窗和弹层

- 所有弹窗使用纯白背景。
- 遮罩统一使用中性黑透明色，约 `rgba(23, 35, 33, 0.42)`。
- 普通确认弹窗最大宽度为 `640rpx`。
- 预约弹层最高不超过屏幕 `80%`，内容区独立滚动。
- 圆角最大为 `12rpx`。
- 标题左对齐，不使用居中警告式标题。
- 不显示拖动条，不暗示弹层可以调整高度。
- 不使用自定义出现、关闭或缩放动画。
- 所有弹窗必须提供明确的取消或关闭操作。
- 窄屏时标题和操作区允许分为两行。

## 11. 状态与反馈

- 状态标签为小型矩形，约 `40rpx` 高、`6rpx` 圆角。
- 状态必须包含明确文字。
- 成功和普通反馈使用微信系统 Toast。
- 需要用户判断或确认的情况使用统一白底弹窗。
- 空状态仅使用简洁文字和最多一个相关操作，不使用插画。
- 首次加载使用微信系统加载提示；局部刷新保留原内容。
- 加载失败保留最近一次成功内容；没有缓存时显示简短错误文字和一个“重新加载”操作。
- 提交失败不得清空表单或周历选择；可修正的业务错误应指向具体字段或时段。
- 禁用状态必须同时降低背景、边框和文字强调度，但文字仍需可读。

## 12. 动效、图片和图标

默认禁止：

- 页面自定义转场
- 弹窗进入/退出动画
- 循环动画和装饰动效
- 背景图片、装饰图片和空状态插画
- 图标宫格、图标按钮和装饰性图标
- 渐变、光晕、彩色阴影和纹理背景

唯一保留的增强反馈是长按进入周历多选时的一次短震动。格子可以使用即时按压状态，但不得添加 CSS 过渡、缩放动画或导致布局移动。

## 13. 响应式与可访问性

- 所有横向按钮组使用可收缩网格，窄屏时允许换行。
- 按钮文字不得因空间不足缩小字号。
- 系统字体放大后，普通内容允许换行，控件使用最小高度。
- 状态颜色需要高对比文字，并辅以文字或边框。
- 触控区域不低于 `64rpx`。
- 内容不得被底部导航、固定操作栏或安全区遮挡。

## 14. 实现约束

1. 优先复用 `tokens.wxss`、`base.wxss` 和 `components.wxss`。
2. 新页面先组合现有类，不创建独立视觉体系。
3. 页面级 WXSS 仅用于该页面独有布局。
4. 禁止在页面 WXSS 中新增主题色硬编码。
4.1. 唯一例外是自定义底部导航为保证选中态稳定而在组件脚本或模板中直接绑定颜色值；该颜色集合必须与 `tokens.wxss` 中对应语义色保持一致。
5. 提交前扫描硬编码颜色、渐变、图片、图标和动画。
6. 真机检查窄屏、系统字体放大、底部安全区和长列表。

## 15. 组件契约

### 15.1 页面容器

| 类名 | 用途 | 限制 |
| --- | --- | --- |
| `.page` | 普通页面根容器 | 最大宽度 `960rpx`，不得用于周历根容器 |
| `.page-intro` | 页面开头的必要说明 | 最多 2-3 行，不重复原生导航标题 |
| `.section` | 区块垂直间距 | 不附带背景、边框或圆角 |
| `.section-title` | 轻量分组标题 | 使用辅助色，不做大标题 |
| `.surface-section` | 白色全宽内容分组 | 内部可以包含列表行，不允许嵌套另一层卡片 |

### 15.2 列表行

`.list-card` 名称为历史保留，视觉上必须表现为列表行：

- 白色背景。
- 只使用底部分隔线。
- 不使用独立圆角和阴影。
- 摘要行最少保留 `88rpx` 可点击高度。
- 行内存在按钮时，按钮与整行点击不能产生冲突。
- 进入详情的列表不在右侧增加“查看”按钮；整行可点击即可。

### 15.3 状态标签

- 标签文字必须完整表达状态。
- 状态值与颜色由统一映射生成，页面不得自行决定颜色。
- 同一状态在周历、列表、详情和管理端必须使用同一语义。
- 长状态允许增加宽度，不允许缩小字号。

### 15.4 普通确认弹窗

适用：拒绝、取消、暂停、停用、维护覆盖、重要变更。

- 标题左对齐。
- 正文说明影响范围。
- 输入字段位于正文下方。
- 操作区固定为“取消 + 明确动作”。
- 危险按钮文案必须具体，例如“确认暂停”，不能只写“确定”。
- 点击遮罩默认不执行危险操作。
- 阻断型重要变更弹窗不得通过遮罩关闭。
- 正文内容较长时只有正文区滚动，标题和操作区保持可见。
- 双按钮在常见手机宽度横排；`320px` 或字体放大导致文案拥挤时改为两行等宽布局。

### 15.5 预约弹层

- 顶部标题和“取消/提交”始终可见。
- 内容区域滚动，操作区不得被底部导航遮挡。
- 不显示拖动条。
- 多时段按日期分组，相邻小时合并。
- 总小时数、审核提示和备注输入顺序固定。
- 提交中锁定关闭与页面切换。

### 15.6 固定操作栏

适用：周历多选、审核详情。

- 与安全区和底部导航互斥，不能重叠。
- 窄屏时允许分为两行。
- 操作按钮等高，文字不得截断。
- 内容区必须增加等于操作栏高度的留白。

## 16. 页面应用矩阵

| 页面 | 主要布局 | 必须遵守 |
| --- | --- | --- |
| 周历 | 全宽排程网格 | 三行顶部结构、固定表头/时间列、横向图例、顶部多选栏 |
| 我的 | 资料摘要 + 2×2 统计 + 线性入口 | 不展示头像，不使用入口宫格，使用蓝色 dashboard 强调 |
| 我的课题 | 课题摘要 + 2×2 统计 + 双列表 | 只展示成员与未来/近 7 天已开启记录 |
| 我的预约 | 分段控件 + 摘要列表 | 列表不直接放取消按钮，目标实现进入详情操作 |
| 预约详情 | 信息分组 + 时间线 + 底部取消 | 全部时段按日期分组，取消为整单 |
| 候补 | 摘要列表 | 不显示名次，待确认操作清晰 |
| 注册 | 单页分区表单 | 只显示当前最小字段、用途说明和协议复选框 |
| 协议/隐私政策 | 纯文本章节 | 正文 `28rpx`、约 `1.75` 行高，不使用 PDF 或外链 |
| 管理首页 | 摘要条 + 待办 dashboard + 分组入口 | 待办优先，使用砖红 dashboard 强调，不使用图标宫格 |
| 审核列表 | 摘要列表 | 不在列表直接审核，进入详情操作 |
| 审核详情 | 业务详情 + 固定操作栏 | 拒绝/通过等宽，拒绝原因弹窗统一 |
| 维护/受限 | 周历多选 + 列表 | 不使用自由文本时间输入作为最终形态 |
| 管理统计 | 指标 + 月度表格 | 不使用用户排行、课题排行或装饰图表 |
| 隐私请求 | 摘要列表 + 详情状态 | 与预约列表和时间线视觉一致 |
| 系统维护 | 居中简洁文字 | 不使用插画或红色错误页风格 |

## 17. 状态视觉映射

| 状态语义 | 背景 | 文字/边框 | 示例 |
| --- | --- | --- | --- |
| 正常/已确认 | `--color-primary-soft` | `--color-primary` | 已预约、本人预约 |
| 信息/审核 | `--color-accent-soft` | `--color-accent` | 待审核、规则复审 |
| 警示/特殊时段 | `--color-warning-soft` | `--color-warning` | 周末、非工作时间 |
| 危险/维护 | `--color-danger-soft` 或维护浅底 | 危险/维护色 | 拒绝、维护取消 |
| 结束/禁用 | `--color-past-soft` | `--color-past` | 已结束、不可编辑 |

不得把审核中和特殊时段使用同一颜色；不得把维护与普通禁用使用同一表现。

## 18. 响应式验收尺寸

至少检查：

- `320px` 等效窄屏：所有按钮和弹窗不溢出。
- 常见手机宽度：周历约显示 3 个日期列。
- 平板/桌面小程序：空间足够时显示 7 天。
- 系统字体放大：列表和表单允许增高，操作文字不截断。
- 带底部安全区设备：底部导航和固定操作栏不遮挡内容。

周历固定尺寸元素必须使用稳定列宽和行高，动态文字不得改变网格尺寸。

建议以 `320px`、`375px`、`430px` 和宽屏四档验收。任何宽度下都不得依靠缩小到低于规范字号来容纳按钮；应优先换行、增加控件高度或改变网格列数。

## 19. 视觉验收清单

每次前端迭代完成后检查：

1. 页面是否重复显示原生导航标题。
2. 是否出现卡片嵌套、每行独立卡片或大面积阴影。
3. 是否新增图片、插画、图标宫格、渐变或动画。
4. 是否存在页面级硬编码主题颜色。
5. 状态是否同时使用文字和颜色。
6. 所有弹窗是否白底、标题左对齐并有明确关闭操作。
7. 危险操作是否说明影响范围并使用具体按钮文案。
8. 按钮是否在窄屏、长文案和字体放大时保持完整。
9. 固定表头、时间列、操作栏和底部导航是否互相遮挡。
10. 空状态是否只有必要文字和最多一个操作。
11. 列表信息是否保持摘要，详情是否进入独立页面。
12. 周历状态颜色是否与图例和详情一致。
13. 加载、空、错误、禁用、提交中五种页面状态是否都保持布局稳定。
14. 更换主题令牌后是否仍能区分审核、受限、维护和过去状态。

建议使用以下静态扫描作为提交前检查：

```bash
rg -n 'linear-gradient|radial-gradient|animation:|transition:|background-image|<image|icon=' miniprogram
rg -n '#[0-9A-Fa-f]{3,8}|rgba?\(' miniprogram --glob '*.wxss'
```

第二条扫描结果原则上只允许出现在 `tokens.wxss`，以及小程序配置中无法使用 CSS 变量的必要位置。
