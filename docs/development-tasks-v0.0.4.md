## 1. 使用说明

本文档将 `v0.0.4` 开发计划拆分为可执行任务清单，按前端、云函数、文档与联调验收四类组织。

执行原则：

1. 先收敛页面结构和数据口径，再进入横版布局细节。
2. 横版页与竖版页优先复用现有业务逻辑，不允许形成双套规则。
3. 首页管理信息必须先完成权限、内容安全和版本控制设计，再接前端展示。
4. 每项任务完成后应及时回填状态与自测结果。

## 2. 前端任务

### 2.1 周历主页 `miniprogram/pages/calendar/`

- [ ] 增加进入横版周历页的明确入口。
- [ ] 首页仅在“已登录用户”进入时拉取管理信息弹窗。
- [ ] 当前存在生效中的管理信息时展示统一白底弹窗。
- [ ] 同一版本消息关闭后不在同一设备重复弹出。
- [ ] 新版本消息发布后可重新弹出。
- [ ] 游客进入首页时不展示管理信息弹窗。

### 2.2 横版周历页 `miniprogram/pages/calendar-landscape/` 或等效页面

- [ ] 新增独立横版周历页并完成 `app.json` 注册。
- [ ] 复用现有周切换、工作时间/全天切换和图例说明。
- [ ] 复用现有周历数据源与状态颜色映射。
- [ ] 复用现有点击分流：预约、待审、维护、详情。
- [ ] 提供明确返回方式。
- [ ] 如支持多选预约，则与竖版页保持同一套规则。

### 2.3 “我的”页面横版适配

- [ ] `miniprogram/pages/profile/index/` 完成横版布局适配。
- [ ] `miniprogram/pages/profile/bookings/` 完成横版布局适配。
- [ ] `miniprogram/pages/profile/project/` 完成横版布局适配。
- [ ] 横版适配后不影响现有跳转、刷新与状态展示。
- [ ] 保持当前视觉规范，不引入图片、渐变或额外动画。

### 2.4 管理首页 `miniprogram/pages/admin/index/`

- [ ] 保留现有“待办直达”结构不回退。
- [ ] 将“其他功能”区收敛为单一入口“页面/课题管理”。
- [ ] 移除管理首页对课题管理的直接裸露入口。
- [ ] 首页入口文案与说明同步更新。

### 2.5 统一管理入口页 `miniprogram/pages/admin/manage-hub/` 或等效页面

- [ ] 新增统一管理入口页并完成 `app.json` 注册。
- [ ] 页面按“运行管理 / 目录管理 / 信息管理”分组展示。
- [ ] 运行管理下承接：维护管理、系统设置。
- [ ] 目录管理下承接：课题管理。
- [ ] 信息管理下承接：首页管理信息。
- [ ] 入口页仅作为导航中枢，不复制子页面业务逻辑。

### 2.6 首页管理信息编辑页 `miniprogram/pages/admin/home-notice/` 或等效页面

- [ ] 支持管理员查看当前管理信息状态。
- [ ] 支持创建或编辑标题、正文与启停状态。
- [ ] 支持显示当前版本号或最近更新时间。
- [ ] 表单文案明确提示“仅对已登录用户首页弹出”。
- [ ] 成功保存后返回明确反馈，并自动刷新当前状态。

## 3. 云函数任务

### 3.1 首页管理信息读取

- [ ] 新增 `cloudfunctions/getHomeNotice/`，或在等效接口中提供只读能力。
- [ ] 仅返回首页展示所需最小字段。
- [ ] 未登录用户请求时返回“无弹窗”结果或最小空结构。
- [ ] 支持按照 `enabled` 和版本字段判断当前是否生效。

### 3.2 首页管理信息更新

- [ ] 新增 `cloudfunctions/updateHomeNotice/`，或在等效接口中提供写入能力。
- [ ] 服务端强校验管理员身份。
- [ ] 标题和正文提交前执行内容安全校验。
- [ ] 内容安全接口失败时闭锁，不允许绕过发布。
- [ ] 每次有效变更自动更新 `version` 或 `updatedAt`。

### 3.3 数据结构与兼容

- [ ] 确认管理信息的存储位置：独立集合或 `settings` 下专用字段。
- [ ] 若复用 `settings`，需保证字段职责清晰，不污染现有系统设置读取。
- [ ] 对前端暴露稳定字段白名单。
- [ ] 为客户端判重展示保留稳定版本标识。

## 5. 联调与自测清单

### 5.1 横版周历

- [ ] 可从首页稳定进入横版周历页。
- [ ] 横版周历展示的预约、维护、待审状态与竖版一致。
- [ ] 管理员横版周历仍可见“课题简称 + 姓名”。
- [ ] 普通用户横版周历不暴露姓名。
- [ ] 横版点击分流与竖版一致。

### 5.2 “我的”页面

- [ ] 我的首页横版下信息区不挤压、不溢出。
- [ ] 我的预约横版下列表和操作按钮仍可读、可点。
- [ ] 我的课题横版下成员与预约信息仍保持清晰层级。

### 5.3 首页管理信息弹窗

- [ ] 游客进入首页时不弹窗。
- [ ] 已登录用户在存在生效信息时会看到弹窗。
- [ ] 关闭后同版本不重复弹出。
- [ ] 发布新版本后会再次触达。
- [ ] 非管理员无法写入或修改管理信息。

### 5.4 管理入口

- [ ] 管理首页只保留一个“页面/课题管理”统一入口。
- [ ] 通过统一入口可进入维护、系统设置、课题管理和首页管理信息。
- [ ] 课题管理原有能力不受入口调整影响。

## 6. 完成定义

满足以下条件后，可视为 `v0.0.4` 开发任务闭环：

1. 横版周历页可稳定使用。
2. 我的首页、我的预约、我的课题完成横版适配。
3. 首页管理信息具备管理员发布、用户触达和同版本免重复弹出能力。
4. 管理首页已完成“页面/课题管理”入口收拢。
5. 文档、任务状态和验收结论已同步更新。
