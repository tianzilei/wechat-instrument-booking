# 仪器预约小程序 v0.0.4 版本描述

版本：v0.0.4

更新日期：2026-06-19

适用场景：版本规划说明、后续上传更新说明草案、内部沟通摘要

---

## 1. 简短版

`v0.0.4` 聚焦页面横版适配、首页运营触达和后台入口继续收拢。版本将以周历横版页为起点，扩展到“我的首页 / 我的预约 / 我的课题”三类高频页面，同时增加仅对已登录用户展示的首页管理信息弹窗，并把课题管理收纳到统一的“页面/课题管理”入口中。

## 2. 可直接用于后续上传更新说明

新增横版周历和“我的”页面横版适配，首页支持向已登录用户展示管理信息弹窗，后台统一“页面/课题管理”入口，进一步收拢课题与页面配置相关功能。

## 3. 详细版

`v0.0.4` 不扩展新的预约业务规则，重点围绕“更适合横屏浏览”“更稳定地向登录用户传达重要信息”“让后台低频配置入口更集中”三条主线推进。

本次更新计划主要包括：

- 新增横版周历页，提升整周时段查看效率，并保持与竖版页一致的数据、状态和点击分流。
- 为“我的首页”“我的预约”“我的课题”补充横版适配，改善高频页面在横屏场景下的信息密度与可读性。
- 增加首页管理信息弹窗，仅对已登录用户展示当前生效的运营或规则提醒，并通过版本控制避免同一条消息重复打扰。
- 新增后台统一入口“页面/课题管理”，将维护管理、系统设置、课题管理和首页管理信息收纳到同一入口体系下。
- 继续保持现有隐私、权限、法务版本和内容安全边界，不因页面扩展而放宽服务端限制。

## 4. 版本关键词

- 横版周历
- 我的页面横版适配
- 首页管理信息弹窗
- 页面/课题管理入口
- 已登录用户触达
- 后台入口收拢

## 5. 对外口径建议

如果需要更偏用户视角的描述，建议使用下面这版：

`v0.0.4` 将让周历和“我的”页面在横屏场景下更易读，首页也会新增仅面向已登录用户的管理信息弹窗；同时，后台会把课题和页面配置相关功能收拢到统一入口，整体结构更清晰。
